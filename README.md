## About Chemistry Explorer

Chemistry Explorer is a browser-based learning tool built for studying chemistry through interactive element data and trend visualizations. It presents the periodic table in a way that makes it easier to compare properties, inspect element details, and follow patterns across the table without leaving the page.

The project is aimed at students, educators, and anyone who wants a quick way to explore core chemistry concepts in a web interface. With Chart.js-driven charts and vanilla JavaScript, it keeps the experience lightweight while still offering a focused set of visual references for element behavior.

---

## Features

- Interactive periodic table explorer for navigating elements
- Ionization energy charts for comparing element behavior
- Electron affinity comparison views
- Melting point and boiling point visualizations
- Electronegativity trend analysis across the table
- Atomic radius trend charts for property comparison
- Electron configuration display for individual elements
- Oxidation states reference and element classification

## Usage

Open the app in your browser and select an element from the periodic table to view its properties and classification.

Use the available charts to compare trends such as ionization energy, electron affinity, electronegativity, and atomic radius. The interface is designed for quick study sessions, classroom demonstrations, and independent review of element relationships.
